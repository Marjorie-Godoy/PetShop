-Objetivo do Software: 

O Software tem o objetivo de estabelecer uma conecção entre uma empresa de Pet Shop e os clientes.

O site possui uma página introdutória ao usuário, com mais detalhes da empresa na intenção de ganhar a confiança de novos clientes, 
para isso conta com páginas para agendar um atendimento e visualizar o seu registro oferecendo a possibilidade de reagendar ou cancelar um atendimento.

-Funcionalidades do Sistema:
    -Página Inicial: banner, galeria de fotos, contatos...

    -Agendamento de atendimentos

    -Registro dos atendimentos feitos pelo cliente

    -Reagendar um atendimento

    -Cancelar um atendimento
